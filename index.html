1.1 电路理论（7 条目）

基尔霍夫定律

ID: 2001 | 标签: KCL, KVL, 电路定律

定义

基尔霍夫电流定律（KCL）：在任一时刻，流入某一节点的电流之和恒等于从该节点流出的电流之和。数学表达式为 $\sum I_{\text{in}} = \sum I_{\text{out}}$ 或 $\boxed{\sum_{k=1}^{n} I_k = 0}$（流入为正，流出为负）。

基尔霍夫电压定律（KVL）：沿任一闭合回路绕行一周，各段电压的代数和恒等于零。数学表达式为 $\boxed{\sum_{k=1}^{m} U_k = 0}$。

物理本质

  • KCL 的物理本质是电荷守恒：根据电流连续性方程 $\oint_S \vec{J} \cdot d\vec{S} = -dq/dt$，对于稳恒电流有 $\oint_S \vec{J} \cdot d\vec{S} = 0$，电荷不能在节点处堆积。
  • KVL 的物理本质是能量守恒：电场是保守场（位场），电位的单值性保证了沿闭合路径的电压代数和为零。

应用方法

标准解题步骤：

  1. 标定参考方向：假设各支路电流方向并标注
  2. 列KCL方程：对 $(n-1)$ 个独立节点应用KCL（$n$ 为节点总数）
  3. 选回路列KVL方程：选择 $m$ 个独立回路（通常为网孔），应用KVL
  4. 联立求解：求解方程组，负号表示实际方向与假设方向相反

独立方程数：KCL方程数 = 节点数 − 1；KVL方程数 = 网孔数；总方程数 = 支路数。

推广形式

  • 广义节点（超节点）：KCL可推广到电路中任一封闭面，通过封闭面的电流代数和为零
  • 交流电路修正：含时变磁场时，KVL需修正为 $\sum v_k = \mathcal{E} = -d\Phi/dt$

注意事项

KCL和KVL仅提供拓扑约束，需结合欧姆定律（元件约束）才能完整求解电路。交流电路中相量形式的KCL/KVL仍然成立：$\sum \dot{I} = 0$，$\sum \dot{U} = 0$。

戴维南定理

ID: 2002 | 标签: 等效电路, 戴维南

定义

任何线性有源二端网络，对外电路而言，总可以用一个理想电压源 $V_{Th}$ 与一个电阻 $R_{Th}$ 串联的电路来等效代替。$V_{Th}$ 等于该二端网络的开路电压 $U_{oc}$，$R_{Th}$ 等于网络内部所有独立电源置零后从端口看进去的等效电阻。

叠加定理

ID: 2003 | 标签: 叠加定理, 线性电路

定义

在线性电路中，任一支路的响应（电压或电流）等于每个独立源单独作用时响应的代数和。核心思想：多电源共同作用 = 各电源单独作用效果的线性叠加。

数学表达

$U = \sum_{k=1}^{n} U_k$ 或 $I = \sum_{k=1}^{n} I_k$，其中 $U_k$、$I_k$ 是第 $k$ 个独立源单独作用时在该支路产生的响应。

使用步骤

  1. 确认电路为线性电路（仅含R、L、C等线性元件）
  2. 选中一个独立源保留，电压源置零→短路，电流源置零→开路（受控源始终保留）
  3. 计算当前电源单独作用下的响应
  4. 对每个独立源重复步骤2~3
  5. 代数叠加（注意参考方向）

注意事项

  • 不能用于功率计算：功率是电压/电流的二次函数，必须先用叠加算出U和I再算功率
  • 含线性受控源时，受控源不能置零
  • 交流电路中需用相量（复数） 计算，不同频率的电源需分别用相量叠加后再合成时域响应

正弦交流电路

ID: 2004 | 标签: 交流, 正弦, 阻抗, 相量

正弦量三要素

正弦电压和电流的瞬时值表达式：$u = U_m \sin(\omega t + \psi_u)$，$i = I_m \sin(\omega t + \psi_i)$。

三要素：幅值 $U_m$（最大值）、角频率 $\omega = 2\pi f$、初相位 $\psi$。

有效值

正弦交流电的有效值：$I = I_m/\sqrt{2} \approx 0.707I_m$，$U = U_m/\sqrt{2}$。日常所说的220V、380V、设备铭牌额定值、仪表显示值均指有效值。

相量法

核心思想：将正弦稳态电路的分析转化为复数运算。相量定义为 $\dot{I} = I\angle \psi_i$，$\dot{U} = U\angle \psi_u$。

相量形式的基尔霍夫定律：$\sum \dot{I} = 0$，$\sum \dot{U} = 0$。微分对应 $j\omega$，积分对应 $1/(j\omega)$。

用于分析不对称三相电路（如故障分析）。将不对称三相系统分解为三组对称分量：

  • 正序分量：$F_1 = \frac{1}{3}(F_a + \alpha F_b + \alpha^2 F_c)$

1.2 电磁场理论（2 条目）

法拉第电磁感应定律

ID: 2006 | 标签: 电磁感应, 法拉第, 楞次定律

定律内容

法拉第电磁感应定律：任何封闭电路中感应电动势的大小等于穿过这一电路磁通量的变化率。公式为 $\mathcal{E} = -d\Phi_B/dt$。对于N匝线圈：$\mathcal{E} = -N d\Phi_B/dt$。

负号代表楞次定律：感应电流的方向总是使得它所激发的磁场来阻碍引起感应电流的磁通量的变化。本质上是能量守恒定律的体现。

磁通量的定义

$\Phi_B = BA\cos\theta$（匀强磁场、平面回路），其中 $\theta$ 为磁场方向与回路法线夹角。

1.3 电机学（3 条目）

变压器工作原理

ID: 2008 | 标签: 变压器, 变比, 等效电路

基本结构与原理

变压器由闭合铁心（硅钢片叠成，减少涡流损耗）和两个线圈绕组组成。基于电磁感应定律工作：一次绕组接交流电源→交变电流→铁心中交变主磁通→二次绕组产生感应电动势。

变比：$k = N_1/N_2 = U_1/U_{20}$，$k>1$ 降压，$k<1$ 升压。

空载运行

空载电流 $i_0$ 包含磁化电流（无功，建立主磁通）和铁损电流（有功）。电力变压器空载电流仅为额定电流的0.5%~5%。空载损耗 $P_0 \approx$ 铁损。

主磁通公式：$U_1 \approx E_1 = 4.44fN_1\Phi_m$。关键结论：主磁通 $\Phi_m$ 由电源电压 $U_1$ 决定，与负载无关。

负载运行

磁势平衡：$i_1N_1 + i_2N_2 = i_0N_1$。负载时二次侧磁势 $i_2N_2$ 产生去磁作用，一次侧增加电流补偿。

等效电路

T型等效电路包含原边漏阻抗 $Z_1$、副边折算漏阻抗 $Z_2' = k^2Z_2$、励磁阻抗 $Z_m$。简化等效电路可忽略励磁支路。

性能参数

电压调整率：$\Delta U% = \beta(r_k^\cos\varphi_2 + x_k^\sin\varphi_2) \times 100%$。电力变压器从空载到满载，电压变化率通常为3%~5%。

效率：$\eta = P_2/P_1 \times 100%$。变压器损耗包括铁损（与负载无关）和铜损（与电流平方成正比）。最大效率条件：铁损 = 铜损。大型变压器效率可达99%以上。

异步电动机

ID: 2009 | 标签: 异步电机, 转差率, 感应电机

基本概念

三相异步电动机（感应电机）转子转速低于定子旋转磁场转速，存在转速差，故得名"异步"。按转子结构分为笼型（鼠笼式，结构简单、应用最广）和绕线式（转子带绕组通过滑环接外部电阻，可改善起动和调速性能）。

工作原理

  1. 三相定子绕组通入对称交流电 → 产生旋转磁场
  2. 同步转速 $n_1 = 60f/p$（工频下：3000/1500/1000/750 r/min对应1/2/3/4对极）
  3. 转子导体切割磁力线 → 产生感应电动势和感应电流
  4. 载流转子导体在磁场中受电磁力 → 形成电磁转矩
  5. 转子沿旋转磁场方向旋转，但 $n < n_1$

转差率

$s = (n_1 - n)/n_1$ 是异步电机最核心的参数。启动瞬间 $s=1$，空载 $s\approx 0.004\sim0.007$，额定运行时 $s_N = 0.01\sim0.06$。

转矩特性

  • 额定转矩：$T_N = 9550 \cdot P_N/n_N$（$P_N$ 单位kW）
  • 最大转矩 $T_m \propto U_1^2$，与转子电阻无关
  • 启动转矩 $T_{st} \propto U_1^2$
  • 启动电流 $I_{st} = (5\sim7)I_N$，启动转矩 $T_{st} = (1.0\sim2.2)T_N$

功率因数调节（突出优点）

功率因数可调是同步电动机最突出的优点。通过调节励磁电流可实现：

火力发电原理

ID: 2112 | 标签: 火电, 发电, 锅炉

热力循环（Rankine循环）：工质（水/水蒸气）经历四个过程：

  1. 锅炉加热（定压吸热）：给水→饱和水→饱和蒸汽→过热蒸汽，压力随参数等级不同（亚临界16.7MPa/超临界24.2MPa/超超临界≥27MPa）
  2. 汽轮机膨胀（绝热做功）：蒸汽在各级叶片中膨胀，热能→动能→机械能，排汽压力约4~10kPa（高度真空）
  3. 凝汽器冷凝（定压放热）：排汽被循环冷却水冷凝为凝结水，放热量占总热量的50%~60%（冷源损失），这是Rankine循环热效率不高的根本原因
  4. 给水泵升压（绝热压缩）：凝结水经低压加热器→除氧器→给水泵→高压加热器→省煤器→锅炉，完成循环

四步选型法：

第1步：按载流量选择导体截面

  • 计算电流 I_c = S / (√3 × U_n) （S为视在功率，U_n为额定线电压）
  • 校正系数乘积 K = K_θ × K_d × K_g × K_m
    • K_θ：温度校正（>25℃时降低，<25℃时升高）
    • K_d：埋深校正（标准深度0.7~1.0m，更深则降低）
    • K_g：多根并列校正（排管中每增加一根载流量减少约10%~25%）
    • K_m：土壤热阻校正（干燥土壤系数0.75~0.85）

第2步：按电压降校核

  • ΔU = √3 × I × L × (Rcosφ + Xsinφ) （三相）

三类稳定定义（IEEE/CIGRE联合定义，结合GB/T 26399-2011）：

1. 功角稳定（转子角度同步能力）：

功角特性方程（单机无穷大系统）：

  • P_e = (EU_s/X_Σ) × sinδ
  • δ为发电机q轴电动势与无穷大系统电压的夹角（功角）
  • 传输功率极限 P_max = EU_s/X_Σ（δ = 90°时）

等面积定则（暂态稳定判据）：

  • 故障期间转子加速 → 动能增加 → 功角增大
  • 故障清除后减速 → 若最大可能的减速面积 < 加速面积 → 失步
  • 极限切除角 δ_cr = arccos[(P_acc_max(δ_m - δ_0) + P_de_max cosδ_m - P_ac_max cosδ_0)/(P_de_max - P_ac_max)]
  • 临界切除时间（CCT）：工程中通过时域仿真反复搜索得到

2. 频率稳定（有功功率平衡能力）：

  • 频率 = f_0 + Δf = f_0 + ΔP / K （K为系统单位调节功率，约20~40MW/0.1Hz）
  • 一次调频（3~15s）：发电机调速器响应，有差调节（调差系数3%~5%）
  • 二次调频（30s~5min）：AGC自动发电控制，无差调节
  • 三次调频（5~30min）：经济调度EDC、机组启停
  • 低频减载（UFLS）：按频率分轮切除负荷，典型设置49.5Hz/49.0Hz/48.5Hz等3~6轮，每轮切除5%~10%负荷

3. 电压稳定（无功功率平衡能力）：

  • PV曲线（鼻形曲线）：系统传输功率到极限点（鼻点）时电压崩溃
  • 静态电压稳定裕度：K_U = (P_max - P_0)/P_0 × 100%，要求 ≥ 8%~10%
  • 动态电压稳定：考虑OLTC调节、发电机过励限制、负荷动态特性等的电压崩溃过程
  • 典型电压崩溃时间：几秒到几十分钟（缓慢型电压崩溃）

低频振荡（0.1~2.5Hz）：

  • 本地模式（0.8~2.5Hz）：单机对系统振荡，阻尼器（PSS）设定于此频段
  • 区域间模式（0.1~0.8Hz）：一群发电机对另一群，阻尼弱，威胁大
  • 抑制措施：电力系统稳定器（PSS，附加励磁控制）是最经济有效的手段，可将阻尼比从0%~1%提升至3%~10%
  • 广域测量：WAMS/PMU（相量测量单元）以50~100帧/s采样，实现低频振荡实时监测

3.1 PLC（3 条目）

PLC工作原理

ID: 2201 | 标签: PLC, 扫描周期

循环扫描工作方式：每个扫描周期依次经历以下阶段：

阶段一：自诊断与通讯处理

  • CPU 自检（ROM/RAM/看门狗）
  • 处理通信任务（与编程器/上位机/其他 PLC 的数据交换）
  • 典型耗时：0.5~3ms

阶段二：输入采样

  • CPU 以扫描方式依次读取所有输入端子的 ON/OFF 状态及模拟量数据
  • 将状态存入 I/O 映像区（输入映像寄存器）
  • 采样结束后，即使外部输入发生变化，映像寄存器内容保持不变直到下个周期

阶段三：用户程序执行

  • CPU 从上到下、从左到右依次扫描用户程序
  • 从输入映像寄存器读取输入状态，从输出映像寄存器/元件映像寄存器读取当前状态
  • 运算结果存入元件映像寄存器（不立即输出）
  • 执行过程中只有输入映像寄存器内容不变

阶段四：输出刷新

  • CPU 将输出映像寄存器状态一次性传送到输出锁存电路
  • 通过输出电路驱动外部负载

PID控制算法

ID: 2210 | 标签: PID, 闭环控制, 参数整定

连续 PID 公式（并联式）：

  • u(t) = Kp×e(t) + Ki×∫e(t)dt + Kd×de(t)/dt
  • 也可写作：u = Kp×(e + 1/Ti×∫e·dt + Td×de/dt)
  • P（比例）：对当前偏差即时响应，Kp 越大响应越快，过大会引起振荡
  • I（积分）：消除稳态误差，累积历史偏差
  • D（微分）：预测偏差变化趋势，抑制超调，但对噪声敏感

位置式 PID（离散化）：

  • u(k) = Kp×e(k) + Ki×Σe(j)×Δt + Kd×[e(k)-e(k-1)]/Δt
  • 输出绝对控制量，需累加所有历史误差，易产生积分饱和

增量式 PID：

  • Δu(k) = Kp×[e(k)-e(k-1)] + Ki×e(k)×Δt + Kd×[e(k)-2e(k-1)+e(k-2)]/Δt
  • 仅输出增量，仅依赖最近三次误差值，天然抗积分饱和
  • 用于电机调速、伺服控制

积分饱和（Anti-windup）：执行器已达极限但误差未消，积分持续累加造成滞后。常用处理方法：

  • 积分限幅：设定积分上下限
  • 积分分离：|e(k)|>阈值时取消积分（仅 PD），|e(k)|<阈值时恢复积分
  • 遇限削弱：输出饱和时冻结积分
  • Back-calculation：用(饱和输出 - 实际输出)反馈驱动积分器回退

站控层通信：

  • 全站统一数据模型（SCL/XML描述变电站一次/二次配置）
  • SCD文件（变电站配置文件）：包含一次接线、IED能力、通信网络、信号关联
  • 工具链：ICD→SCD→CID/CCD（标准化配置流程）

时间同步：

  • IEEE 1588 PTP精密时钟同步协议（T-CM混合模式，精度<1μs）
  • 简单网络时间协议SNTP（精度1~10ms，仅适用于站控层）
  • IRIG-B码（传统硬接线对时，精度<1μs）

8.5 施工验收（1 条目）

GB 50303建筑电气施工验收规范

ID: 2706 | 标签: GB50303, 施工验收

适用范围：建筑电气工程施工质量验收（强电+防雷接地部分）。

核心验收子分部：

变配电室（第4章）：

  • 接地干线：不少于2处与接地网连接，镀锌扁钢≥25×4mm
  • 变压器安装：气体继电器本体倾斜度1%~1.5%，油枕侧高1.5%
  • 高压柜：五防功能齐全，机械联锁试验灵活可靠
  • 低压柜：抽屉单元推拉/插入灵活，机械联锁位置准确

成套配电柜/控制柜（第5章）：

  • 基础槽钢：顶部高出抹平地面≥10mm（手车式柜≥20mm），水平度<1‰
  • 柜体垂直度：每米<1.5mm，相邻柜顶部高差<2mm
  • 接地：柜体与基础槽钢不少于2处可靠接地

母线安装（第6章）：

  • 封闭母线：安装垂直度/水平度<2mm/m，全长≤10mm
  • 插接母线：穿楼板处设防水台阶（≥50mm），穿墙处密封防火
  • 母线搭接：力矩值按GB 50149规定，螺栓紧固力矩抽检5%

电缆敷设（第7章）：

  • 电缆沟：支架间距≤1m（水平控制电缆≤0.8m），接地可靠
  • 电缆终端头制作：严格按照工艺（热缩管/冷缩管收缩均匀）
  • 防火封堵：电缆穿墙/孔洞采用防火堵料封堵密实，耐火极限≥1h

照明安装（第8~11章）：

  • 插座回路：≤10个插座/回路，额定电流≤16A
  • 照明回路：灯头数≤25个/回路（不含回路灯数时，≤20个灯/回路）
  • I类灯具必须接PE线（金属外壳灯具）
  • 应急照明：连续供电时间≥90min（GB17945强制）

防雷接地（第12章）：

  • 接地装置：接地电阻≤1Ω（综合楼/变电所），≤4Ω（一般建筑）
  • 接闪带：支持卡间距≤1m，转弯处≤0.5m，焊接处防腐
  • 等电位联结：总等电位(MEB)+局部等电位(LEB)，卫生间/泳池等LEB必须做

典型不合格项目：

  • PE线/接地线截面不足（最常见，约**30%**的验收问题）
  • 配电箱内接线混乱、标识不清
  • 照明回路零线和相线接反
  • 电缆防火封堵不到位

EPC合同关键条款：

  • 固定总价（Lump Sum）：若非业主变更范围和条件，总价不可调
  • 变更管理：设计变更→变更令→费用/工期调整（严格执行变更程序）

EPC风险管理：
