## 10.1 设计方案模板（2 条目）

### 技术方案编制要点

**ID**: 3002 | **标签**: `技术方案`, `设计`

**技术方案标准结构**（电气工程类）：

| 章节 | 内容 | 关注重点 |
|------|------|----------|
| **一、项目概况** | 项目名称/地点/规模/建设背景/设计范围 | 用户最关注的部分——让评审专家快速建立总体认识 |
| **二、设计依据** | GB/DL/IEC标准清单、用户需求书(UFD)、技术规范书 | 引用最新有效版本标准（注意是否有废止/更新） |
| **三、技术路线** | 主接线方案/配电方案/控制方案/保护方案 | 论证方案先进性+可靠性+经济性（三重考量） |
| **四、设备选型** | 开关柜/变压器/UPS/EPS/PCS型号规格 | 关键参数表+选型计算过程+裕度说明 |
| **五、系统图** | 一次系统图、二次原理图、控制逻辑图 | 标注关键节点参数（电压/电流/短路容量） |
| **六、工程量清单** | 设备清单/材料表/施工量清单 | 格式与投标报价表一致，便于评审对照 |
| **七、技术经济指标** | 总投资/单位造价/年运行费用/节能率 | 全生命周期成本(LCC)分析更有说服力 |

**编制技巧**：
- 方案结构对标招标文件/用户需求书的**评分点**，逐一响应不遗漏
- 技术亮点突出**3~5个**关键差异化优势（不必贪多）
- 用**对比表**展示方案选型依据（如A型号 vs B型号对比选型论证）
- **风险识别**提前暴露：供电可靠性分析、施工难点预判、过渡方案设计

**常见错误**：
- 照抄标准规范不结合具体项目（专家一眼看穿）
- 设备参数只罗列不解释选择理由
- 缺少备选方案和可行性与经济性论证

→ 关联：[规范与标准](规范与标准.md) — 引用GB/DL标准

### 电气施工图设计流程

**ID**: 3004 | **标签**: `施工图`, `设计流程`

**设计阶段划分与交付物**：

| 阶段 | 深度要求 | 核心交付物 | 周期参考 |
|------|----------|-----------|----------|
| **初步设计** | 确定方案/主要设备选型/投资概算 | 初步设计说明书、概算书、主要设备表、各专业互提资料图 | 大型项目1~3个月 |
| **施工图设计** | 全部图纸可指导施工/设备采购 | 完整图纸+技术规范书+工程量清单 | 中型项目1~2月 |
| **施工图会审** | 各参建方审图、问题整改 | 会审纪要、图纸修改单 | 1~2周 |
| **设计交底** | 向施工方解释设计意图 | 技术交底记录 | 1~2天 |

**施工图图纸目录**（典型电气专业）：

| 图号 | 图纸名称 | 说明 |
|------|----------|------|
| E-00 | 图纸目录+设计说明+图例 | 包含主材表 |
| E-01 | **高/低压配电系统图** | 含干线电缆型号、保护整定值 |
| E-02 | **变配电室平面布置图** | 柜位编号、通道尺寸、接地布置 |
| E-03 | **照明平面图** | 每层一个，标回路编号/管径/线径 |
| E-04 | **动力平面图** | 设备定位、管线走向、控制箱位置 |
| E-05 | **防雷接地平面图** | 接闪带布置、接地网、等电位联结 |
| E-06 | 消防电气平面图 | 应急照明/疏散指示/消防配电 |
| E-07 | 弱电智能化系统图 | 综合布线/安防/楼控/能耗 |

**设计深度的三个层级**（住建部《建筑工程设计文件编制深度规定》）：
- **扩初（方案深度）**：确定主要指标和方案可行性
- **施工图（施工深度）**：每台设备定位、每根电缆路径、每个安装大样
- **深化设计（竣工深化）**：施工方/供货方根据现场细化图纸

**设计质量控制**：
- **三级校审**：设计→校对→审核→审定（签字盖章责任制）
- 设计变更：**变更通知单**经原审核人签字，重大变更需重新图审
- 图纸版本控制：修订版号+日期（RevA→RevB→RevC）

→ 关联：[规范与标准](规范与标准.md) §8.6 GB/T 4728制图标准

## 10.2 投标文件（1 条目）

### 商务标书编制

**ID**: 3003 | **标签**: `投标`, `商务标`

**投标文件组成（三卷）**：

**第一卷 商务标**（资格证明文件）：
- 投标函+法定代表人授权委托书
- 营业执照/资质证书（**电力工程施工总承包**/承装(修、试)电力设施许可证等）
- 业绩证明：近3~5年同类项目合同+竣工验收证明（重点：**金额匹配**、**技术路线匹配**）
- 财务状况：审计报告、银行资信证明、纳税记录
- 项目经理及技术人员资格证书（注册电气工程师/建造师/安全员）

**第三卷 技术标**（与技术方案合并编制）：
- 对招标文件的**逐条响应**（"★"号条款的偏离被视为废标）
- 设备选型技术参数表（逐项填列）
- 施工组织设计/供货计划/安装调试方案
- 质量保证/售后服务承诺（质保期、响应时间、备件保障）

**第二卷 报价标**：
- **已标价工程量清单**（与招标清单格式严格一致）
- 设备价格表（主机+附件+备品备件）
- 安装调试费、培训费、运保费分解
- **报价汇总表**（含税/不含税）

**评分要点分析**（国网/南网**综合评分法**常用权重）：

| 评分项 | 权重 | 策略 |
|--------|------|------|
| 技术方案 | 30%~40% | **主攻项**——差异化亮点+充分依据 |
| 业绩 | 15%~25% | 必须吻合招标"同类项目"定义 |
| 报价 | 20%~30% | 基于成本+竞争对手历史报价大致估算 |
| 资质 | 10%~15% | 门槛要求，必须全部满足 |
| 服务 | 5%~10% | **质保期**和**响应时间**常是关键隐性要求 |

## 10.3 国网项目流程（1 条目）

### 国网招投标流程

**ID**: 3001 | **标签**: `国网`, `招投标`, `ECP`

**国网电子商务平台ECP2.0操作全流程**：

| 环节 | 时间节点 | 操作要点 |
|------|----------|----------|
| **招标公告** | 发布日起 | 关注ECP2.0信息系统（sgcc.com.cn）公告栏 + 微信公众号推送 |
| **投标报名** | 公告期内 | CA数字证书登录，下载招标文件（**注意澄清/修改公告更新**） |
| **投标保证金** | 开标前 | 投标保证金保函或电汇（金额为预算的**1%~2%**，上限80万元） |
| **投标文件编制** | 公告期+15~30天 | **三卷制**（商务+技术+报价），装订要求严格（页码/签章/密封） |
| **开标** | 公开/邀请 | 线上解密+公示报价（ECP2.0自动唱标） |
| **评标** | 开标后1~2周 | 初评(资格性)→详评(技术+商务+报价)→推荐中标候选人 |
| **中标公示** | 评标完成 | 公示期**3天**（可质疑投诉——异议须在公示期内书面提出） |
| **合同签订** | 中标通知后 | 技术协议+商务合同+廉企协议，设备类合同附**技术参数确认表** |

**ECP2.0关键功能**：
- **供应商资质能力核实**（一纸证明）：年度核实，结果共享
- **电子投标**：加密上传（CA证书+RSA加密），开标时解密
- **远程异地评标**：主会场+分会场视频连线

**评标方法**：
- **综合评分法**（主流）：技术分+商务分+价格分（按权重加权）
- **经评审的最低投标价法**：技术商务合格，**最低价中标**（适用于标准化程度高的产品）
- **国网重点管控**：**"三不"原则**（不打招呼、不递条子、不围标串标），违法行为将被列入**黑名单**（全网禁入1~3年）

**项目执行关键节点**：
- 技术联络会（合同签订后）：确认技术细节、接口、提资进度
- 设计确认（土建/安装前）：确保安装条件与设备匹配
- 出厂验收（FAT）：关键设备**出厂前必须验收**（含型式试验报告核查）
- 现场验收（SAT）：到货验收+安装调试+竣工验收

→ 关联：[规范与标准](规范与标准.md) §8.3 Q/GDW企标

## 10.4 项目归档（1 条目）

### EPC总承包模式

**ID**: 3005 | **标签**: `EPC`, `总承包`

**EPC总承包组织架构**：

业主（项目法人）
└── **EPC总包方**（设计+采购+施工一体化责任主体）
    ├── 设计分包（可研/初设/施工图）
    ├── 采购分包（设备招标/监造/催交）
    └── 施工分包（土建/安装/调试）

**各方责任划分**：

| 角色 | 责任 | 风险重点 |
|------|------|----------|
| **业主** | 提供项目核准/土地/环评，支付工程款 | 建设条件+资金保障 |
| **EPC总包** | **总价包干**，承担设计/采购/施工全部风险 | **成本超支**、工期延误、质量缺陷 |
| 设计分包 | 按合同完成设计 | 设计缺陷/深度不足→**设计变更索赔** |
| 施工分包 | 按图施工、安全责任 | 安全事故、质量问题 |
| 监理 | 质量/进度/投资控制（业主委托） | 监理失职/与总包合谋 |

**EPC合同关键条款**：
- **固定总价**（Lump Sum）：若非业主变更范围和条件，总价**不可调**
- 变更管理：设计变更→变更令→费用/工期调整（**严格执行变更程序**）
- 里程碑付款：设计完成30%/设备到场30%/安装完成20%/验收10%/质保金10%
- 质保期：通常**2年**（从竣工验收合格日起算）
- 履约保函/预付款保函：合同金额的**5%~10%**

**EPC模式的适用范围与决策**：

| 维度 | 适用EPC | 不适用EPC |
|------|---------|-----------|
| 项目规模 | **大型电站/变电站**（50MW+或110kV+） | 小型技改/零星工程 |
| 技术确定性 | **技术成熟**、标准化的**交钥匙工程** | 新技术/研究性项目 |
| 用户需求 | 业主明确功能需求但缺乏工程管理能力 | 业主有强大工程团队、希望深度参与 |

**EPC风险管理**：
- **设计优化**：EPC核心盈利手段——在设计阶段优化方案（降低造价，但必须满足功能要求）
- **设备集中采购**：利用总包议价能力降低采购成本（批量折扣5%~15%）
- **工期管理**：关键路径法(CPM)，**最晚开工日**和**最晚交货日**为硬约束
- **安全管理**：总包负总责，**"一票否决"**制度（安全不达标不得开工）

**常见EPC类型**：
- **设计采购施工总承包**（全EPC）：最完整的交钥匙工程
- **设计采购总承包(EP)**：业主负责施工
- **设计施工总承包(DB)**：业主负责采购
- **交钥匙工程(Turnkey)**：EPC+试运行+人员培训，达到**"一转钥匙就能生产"**的标准

## 10.5 技术报价（1 条目）

### 成本估算与报价

**ID**: 3006 | **标签**: `成本`, `报价`, `清单计价`

**报价费用构成**：

| 费用项 | 内容 | 占比参考 |
|--------|------|----------|
| **设备费** | 主要设备+辅材+备品备件+专用工具 | **55%~70%** |
| **安装费** | 设备安装+管线敷设+调试 | **10%~15%** |
| **设计费** | 方案/施工图/竣工图 | **3%~5%** |
| 管理费 | 项目管理/现场办公/交通差旅 | 5%~8% |
| 税金 | 增值税13%+附加税 | 10%~14% |
| 利润 | 目标利润 | 5%~12%（视竞争强度） |

**计价方法对比**：

| 方法 | 适用场景 | 特点 |
|------|----------|------|
| **工程量清单计价**（GB 50500） | 公开招标项目（国网/南网） | 单价合同，按实结算，**最常用** |
| **定额计价** | 一般工程项目 | 按国家/地方定额计价，费率高 |
| **成本加成** | 技术不确定/批量小 | 风险由业主承担，利润透明 |
| **固定总价** | EPC/交钥匙工程 | 总价包干，风险在总包方 |

**报价策略**：

| 策略 | 适用情境 | 方法 |
|------|----------|------|
| 高价策略 | 技术独特/竞争少/品牌溢价 | 利润目标**15%~20%** |
| 竞争策略 | 市场成熟/竞争对手多 | 利润**5%~8%**，靠规模盈利 |
| 低价策略 | 进入新市场/业绩需求 | **保本+微利**（甚至略亏），以业绩换市场 |
| 优惠策略 | 老客户/战略客户 | 正常报价×**0.90~0.95**折扣 |
| 不平衡报价 | 工程量可能变更的项目 | 调高早期付款项单价（改善现金流） |

**成本估算方法**：
- **详细估算法**（精确度>90%）：逐项计算设备/材料/工时/管理费
- **参数法**（精确度70%~80%）：按"每kVA造价"、"每回路造价"等指标估算
- **类比法**（精确度50%~60%）：参照历史同类项目价格按规模等比调整

**设备定价基准**（参考2025~2026年市场价）：

| 设备 | 价格范围 | 备注 |
|------|----------|------|
| 干式变压器SCB13-1000/10 | ~**25~35万元** | 含温控/风机/外壳 |
| KYN28A-12中置柜 | ~**3~6万元/面** | 含VS1断路器/综保 |
| MNS低压柜 | ~**2~4万元/面** | 含框架/塑壳断路器 |
| 储能PCS 100kW | ~**10~15万元** | 含EMS通讯 |
| SVG ±10Mvar | ~**80~120万元** | 含连接电抗器 |
| APF 100A | ~**3~5万元** | 三相四线 |

**报价书格式要素**：
- 封面（项目名称+报价方+日期+签章）
- 报价函（总价大写+小写，有效期至少**30~60天**）
- 报价明细表（按设备清单逐项列明：名称/型号/数量/单价/总价）
- 技术参数差异表（逐条响应）
- 供货范围/服务承诺说明
