## 9.5 电能质量设备（2 条目）

### SVG静止无功发生器

**ID**: 2806 | **标签**: `SVG`, `无功补偿`

**产品参数**：

| 参数 | 低压SVG | 中压SVG |
|------|---------|---------|
| 额定电压 | AC 380V/690V | AC 6kV/10kV/35kV |
| 补偿容量 | ±**50~±500kvar** | ±**1~±50Mvar** |
| 响应时间 | **<5ms**（最快1ms） | <10ms |
| 自身谐波 | THD<**3%** | THD<3% |
| 效率 | >**98%** | >98% |
| 拓扑 | 两电平/NPC三电平 | **MMC级联H桥** |
| 冷却 | 智能风冷 | 智能风冷/水冷 |

**核心技术**：**级联H桥（链式SVG）**为中高压主流方案，每相由多个H桥子模块串联，直接接入6~35kV电网。控制策略采用**dq解耦双闭环**（电压外环+电流内环）+ **载波移相PWM**（等效开关频率显著提高，降低输出谐波）。

**与电容器组混合方案（SVG+FC）**：SVG承担动态无功调节（感性/容性双向连续），并联电容器组(FC)提供稳态容性无功基础量——既满足动态响应要求，又降低总投资成本（SVG容量选为总无功需求的**30%~50%**）。

→ 关联：[电能质量治理](电能质量治理.md) §6.2 SVG原理、§6.6 MMC拓扑

| 参数 | 数值 |

| 谐波滤除率 | **≥95%** |
| 全响应时间 | **<5ms** |
| 效率 | ≥**97%** |
| 控制策略 | **PI+重复控制**复合 |

**工作模式**：谐波补偿（默认，最常用）、无功补偿（可设置功率因数目标）、三相不平衡补偿（零序+负序）。

**安装方案**：
- 集中补偿（配变低压侧整体补偿）
- 就地补偿（非线性负载前端补偿——效果最佳）
